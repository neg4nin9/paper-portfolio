# Capturas de proyectos

Deja aquí las capturas reales de cada proyecto. **No hay que tocar código**: el
sitio detecta el archivo por su nombre y reemplaza el dibujo (la "lámina" SVG)
de ese proyecto. Si no hay archivo, se queda el dibujo.

Ahora mismo solo está `linktrim.jpg`; los otros cuatro siguen dibujados.

## Nombre del archivo

El nombre debe ser exactamente el *slug* del proyecto:

| Proyecto         | Archivo                     |
| ---------------- | --------------------------- |
| LinkTrim         | `linktrim.jpg`              |
| Winter Olympics  | `winter-olympics.jpg`       |
| Grupo Zenith    | `grupo-zenith.jpg`          |
| CRFiguras        | `crfiguras.jpg`             |
| Almacenes Unidos | `almacenes-unidos.jpg`      |

Extensión: `.jpg`, `.jpeg`, `.png`, `.webp` o `.avif`, en minúsculas.

## Especificaciones

- **Proporción 16:10** ideal (la lámina recorta a ese marco con `object-cover`,
  así que cualquier horizontal sirve: 2:1, 16:9, etc. Se recorta por los lados).
- **1600 px de ancho** es el tamaño recomendado; 1200 funciona igual.
- **Peso por debajo de 400 KB**: exporta JPG calidad 80 o WebP.
- Captura la interfaz, no la maqueta de Figma con fondos de escritorio: se lee
  como evidencia de algo construido.
- Las capturas se sirven tal cual, a color. El duotono es solo del retrato.
- Al pulsar una captura en el sitio se abre a tamaño completo, así que conviene
  que el texto de la interfaz se lea al tamaño original.

## Reemplazar o quitar una captura

- Sustituir: borra el archivo y pon otro con el mismo nombre.
- Volver al dibujo: borra el archivo. Nada más.
